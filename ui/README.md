# ui / the local application

```bash
python ui/serve.py
```

Then open **http://127.0.0.1:8731**. Stop it with Ctrl-C. There is nothing to install: it is
Python's standard library and nothing else, so it runs on a workstation with no package manager,
no internet, and no administrator.

---

## What it is for

The board on `site/surveyor.html` is a published artifact — correct, cited, and dead. This serves
the same folds live and **makes the citation a link**:

- the grey handles beside every number reach **the tape events behind it**
- a check id reaches **its predicate, its anchor and why that anchor, the regulatory clause it runs
  under byte-matched to a hash-pinned source, its fixtures, and every verdict it returned**
- a clause reaches **the mapping and its verification status**
- the three folds — line of sight, committee packet, survey binder — render with their event
  citations linked

*Every line links to its evidence* stops being a claim in a footer and becomes the way you move
around the record.

## What it cannot do, by construction

**It cannot write.** `GET` is the only method; `POST`, `PUT`, `DELETE` and `PATCH` return 405 with
an explanation. There is no code path from this application to the tape, the checks or the record.
The quality record is written by people under their own names (law A5), and an interface that could
write it is the one thing this architecture forbids.

**It cannot leave the machine.** Bound to `127.0.0.1`, never `0.0.0.0` — a bind address is a policy
statement and the common default is the wrong one. No CDN, no font service, no analytics, no script
tag, no outbound request of any kind; the stylesheet is inline and the fonts are whatever the
machine already has. A `Content-Security-Policy: default-src 'none'` header says the same thing to
the browser. **An air-gapped workstation renders this identically to a connected one**, which is
the test that matters — note that the public product page loads a font service and this
deliberately does not.

**It cannot serve a file.** Every response is rendered from objects in memory. There is no document
root, so there is no path traversal to get wrong.

## The numbers are real reads of a synthetic tape

The banner says so on every page, and it is generated rather than typed so it cannot be forgotten
when the source changes. The floor, the clocks, the crosswalk and the folds are real; the *record*
they run over is generated by `experiments/f-fixture/generate.py`. They become a programme's
numbers when F-RETRO runs on that programme's historical charts, and not before (law E2).

## How it is kept honest

```bash
python ui/serve.py --selftest
```

renders every route and follows every link. **A dead citation is worse than a printed one, because
it looks checkable** — so this is graded on every gate run as part of `G-EVIDENCE-LINKS`, alongside
a check that the app references nothing off this machine and refuses every write method.

## Pointing it at a real tape

`World` in `serve.py` builds its events from the synthetic generator. A site swaps that one call
for a read of its own product tape (`ledger/tape.py`, hash-chained, append-only) and changes
nothing else: every view is a pure function of an event list. That substitution is the whole
distance between this and the shipped article.
